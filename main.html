How to Play

📖

Objective

You are tasked with fixing broken code. Analyze the Reference Code to understand how it should work, and find the bug in the Debugging Code.

Game Mechanics

  • Timer: Each level has a time limit. If the time runs out, you lose a life.
  • Lives (♥♥♥): You start with 3 lives. If you select a wrong answer or run out of time, you lose one. Lose all 3, and it's Game Over!
  • Scoring: Earn 100 points for a correct answer, plus bonus points based on how much time is left on the clock.
  • Hints: Stuck? Use the Hint button, but be careful as the clock keeps ticking!
